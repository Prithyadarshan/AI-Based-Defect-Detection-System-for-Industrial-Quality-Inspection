# AI-Based Infrastructure Inspection System

## Description

This project detects infrastructure defects such as:

- Crack
- Corrosion
- Pothole
- Spalling
- Normal Surface

using Deep Learning (CNN).

## Technologies

- Python
- TensorFlow
- OpenCV
- NumPy
- Scikit-learn
